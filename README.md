# Dracula & Alucard themes for Halloy

Dracula and Alucard themes for [Halloy](https://github.com/squidowl/halloy).

Follows the [Dracula spec](https://draculatheme.com/spec).

## Usage

Copy these to your `~/.config/halloy/themes` folder.

Then add the themes to your `~/.config/halloy/config.toml`:

```toml
theme = { dark = "dracula", light = "alucard" }
```
